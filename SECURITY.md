# Security Policy

## Reporting a vulnerability

Synapedge is a code-generation tool; the most likely "security" issues are generated
code that is incorrect in a way that could matter for safety-critical deployments, or
issues in the Python tooling.

If you find a vulnerability, please report it privately **Asadshafi@reuna-ai.com** or **AyaanAbbasi@reuna-ai.com**
rather than opening a public issue. Include:

- a description of the issue,
- how to reproduce it (model, target, command),
- and the impact you foresee.

We will acknowledge receipt and work with you on a fix and disclosure timeline.

## Supported versions

This is an early-stage project; only the latest `main` is supported.
